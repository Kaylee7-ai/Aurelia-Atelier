# VECLRA

Open `index.html` in a browser, or push the folder to GitHub and deploy on Netlify or GitHub Pages.

## Edit these first
- `assets/js/script.js`: set `WA` to your WhatsApp number (country code, no +), and edit the `RAW` product list.
- Real photos: save images in `assets/images/` and set each product's `img` (for example `assets/images/VL001.jpg`).
- Colours: the variables at the top of `assets/css/style.css`.

## Working now
Catalogue, search, filters and sorting, category pages, product pages (`product.html?id=VL001`), bag, wishlist (saved in the browser), WhatsApp ordering.

## Not built yet (needs a backend)
Customer accounts, admin dashboard, inventory, card and Mobile Money payments, order tracking, policy pages. Planned: Supabase for auth, database and images, plus Paystack or Hubtel with server-side payment verification.
