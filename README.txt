How to use:
1. Open index.html in a browser to preview it.

3. For a real client, replace the fictional brand name, email, copy, colors, and service details.

The demo uses only HTML, CSS and JavaScript. No paid software, domain, hosting, API key, or subscription is required to edit or preview it.
